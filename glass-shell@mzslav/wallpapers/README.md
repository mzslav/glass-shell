# Glass Shell wallpapers

Put pairs of pictures here:

    NAME-light.jpg   used in Light style
    NAME-dark.jpg    used in Dark style

(jpg, jpeg, png, webp or jxl). A single `NAME.jpg` is used in both styles.
Choose the pair in Glass Shell's settings (Appearance → Wallpaper) or with
`gsettings ... set org.gnome.shell.extensions.glass-shell wallpaper 'NAME'`.
New files show up in the list at once.

Pictures in this folder are not part of the git repository (see .gitignore),
so you can keep wallpapers here that you may not share.
